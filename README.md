# TanStack Start + Better Auth + Convex template

A boring SaaS starter kit, built to be built upon.

- Frontend: React 19 + TanStack Start
- Backend: Convex + Better Auth

## Make It Your Own

You can easily fork and clone this repository, then make it your own by going to [ui.shadcn.com](Shadcn Theme Creator) and creating a theme you like. Once done, copy the code and apply it with `pnpm dlx shadcn@latest apply --preset <code> -c apps/web` in the root of this directory.

Do note, we use a different dark-theme selector than the default, so you will want to delete the `[data-theme='dark']` block from the css file, then change the newly added `.dark` selector with the previously deleted one.
